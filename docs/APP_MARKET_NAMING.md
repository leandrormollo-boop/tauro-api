# Nombres de las aplicaciones por mercado

Convención oficial de marca para las integraciones de e-commerce:

| Alcance | Nombre visible |
| --- | --- |
| Marca madre | **Tauro Solutions** |
| Aplicación para Argentina | **Tauro Solutions Ar** |
| Aplicación para Estados Unidos | **Tauro Solutions Us** |

El sufijo identifica el mercado de la aplicación, no la plataforma. Por eso la
aplicación argentina debe llamarse **Tauro Solutions Ar** tanto en Shopify como
en Tiendanube. La aplicación estadounidense será **Tauro Solutions Us** en las
plataformas donde se publique.

No usar como nombre público de aplicación `TAURO Solutions`, `Tauro Nacionales`
ni variantes totalmente en mayúsculas. Los identificadores internos, handles y
URLs pueden mantenerse estables aunque cambie el nombre visible.
